# DLStore

تطبيق iOS لتنزيل ومشاركة تطبيقات App Store باستخدام Apple ID.

[![Build DLStore IPA](https://github.com/YOUR_USERNAME/DLStore/actions/workflows/build.yml/badge.svg)](https://github.com/YOUR_USERNAME/DLStore/actions/workflows/build.yml)

## المميزات
- 🔐 تسجيل دخول بـ Apple ID (مع دعم التحقق بخطوتين)
- 🔍 البحث في App Store
- 📥 تنزيل ملفات IPA
- 👥 دعم حسابات متعددة
- 🌍 دعم متاجر متعددة (السعودية، الإمارات، US...)

## التثبيت

### تحميل IPA جاهز
حمّل من [Releases](https://github.com/YOUR_USERNAME/DLStore/releases) وثبّت عبر **AltStore** أو **Sideloadly**.

### بناء يدوي
يحتاج macOS + Xcode 15+.
